# 🎞️ 人生记录本 · 深夜胶片溯源馆 (Life Novel & Provenance Archive)

> **把散落在岁月里的随笔与光影，冲洗成一条可溯源的生命长卷。**

一个采用 **「深夜胶片馆 / 时光博物馆」** 电影感美学的个人人生素材链记录与溯源展示系统。支持 **随笔创作**、**自己上传配图 / AI 读文记忆显影配图**、**流光时间轴长卷**、**高德地图人生足迹溯源模式** 以及 **一键生成公开分享链接**。

---

## ✨ 核心功能

### 1. 🌌 展示页面（时光博物馆 · 三种浏览模式）
* **✨ 流光时间链模式**：根据事件发生年份自动编排人生节点，基于出生年份自动换算当时年龄（如 `6岁 · 童年拾遗`、`18岁 · 少年求索`），支持正序溯源与倒序回溯。
* **🗺️ 高德地图足迹模式**：
  * 接入高德地图瓦片引擎（支持切换 **高德深夜胶片底图**、**高德卫星影像图**、**高德标准街道图**）。
  * 按时间顺序将整个人生节点串联为发光迁徙轨迹，支持点击 **「▶️ 巡航播放人生轨迹」** 自动飞跃各个年龄段的人生坐标并弹出 35mm 胶片记忆卡。
* **🖼️ 35mm 底片画廊模式**：电影宽画幅网格浏览，点击任意卡片可开启 **全屏胶片放映厅 (Lightbox)** 沉浸阅读。

### 2. 🎬 管理页面（胶片剪辑与配图工作台 `/studio`）
* **随笔与时间锚点**：支持精确日期或模糊时间描述（如 *“15岁 · 台风过境的晚自习”*），内置随机回忆灵感提示。
* **高德坐标自动定位与地图选点**：输入城市或地点名称即可自动匹配高德 GCJ-02 经纬度，也支持打开 **「🗺️ 在高德地图上选点」** 点击地图精确拾取坐标。
* **双模配图工坊**：
  * **✨ AI 记忆显影（AI 配图）**：一键从中文随笔提炼画面意境 Prompt，内置 5 款电影画风预设（柯达暖调 35mm、王家卫霓虹胶片、新海诚暮色光影、暗调电影叙事、黑白银盐纪实）。默认开启免配置免费 AI 显影通道，同时支持配置硅基流动 (SiliconFlow)、智谱 CogView、OpenAI 等自定义 API Key。
  * **📷 自己配图（本地上传）**：支持上传实拍照片并叠加 5 款胶片调色滤镜。
* **公开/私密颗粒度控制**：单条随笔可随时切换公开或私密状态。

### 3. 🔗 一键分享公开溯源链 (`/share/:slug`)
* 在管理页面点击 **「🔗 分享溯源链」** 即可生成专属分享链接，支持自定义展馆标题、寄语及可选 **访问暗号（密码保护）**。
* 访客点开链接即可进入纯享只读版「人生溯源馆」，浏览流光时间链或高德足迹地图。

## 🚀 快速启动

本项目基于原生 Node.js 构建，**零外部 npm 依赖安装等待**，克隆后即可直接启动：

```bash
node server.js
```

启动后访问：
* **展示页面（时间链 + 高德地图模式）**：`http://localhost:3080/`
* **管理页面（随笔编辑 + AI 配图 + 分享）**：`http://localhost:3080/studio`
* **示例公开分享链接**：`http://localhost:3080/share/linshen-1998`
